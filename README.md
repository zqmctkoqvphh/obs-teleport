## Overview

OBS Teleport is a free OBS Studio plugin that streams audio and video between OBS instances on the same local network using Bonjour/Avahi zero-configuration auto-discovery — no NDI license, no IP addresses, no external server required. Sub-frame network latency makes it ideal for multi-PC streaming setups where one gaming PC sends its capture feed directly to a dedicated streaming PC.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OBS Teleport** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Zero Configuration** | Bonjour/Avahi auto-discovery — no IP setup or manual configuration needed |
| **Sub-Frame Latency** | Network transport latency suitable for live multi-PC streaming pipelines |
| **Multi-Receiver** | One Teleport sender can feed multiple OBS receiver sources simultaneously |
| **No License Fees** | Fully free — no NDI license or external streaming server subscription |
